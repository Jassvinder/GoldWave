# Release Checklist

> Populate this only after the deployment runbook is active. Check items must be concrete and verifiable.

## Pre-release

- [ ] Scope and rollback path confirmed.
- [ ] Relevant tests, lint, typecheck, and build completed or exception recorded.
- [ ] Required configuration changes reviewed without exposing values.
- [ ] Migration, compatibility, and backup implications reviewed.

## Release

- [ ] Correct environment and version confirmed.
- [ ] Deployment / migration procedure completed.
- [ ] Release evidence recorded.

## Post-release

- [ ] Smoke checks passed.
- [ ] Error logs, health checks, and key metrics reviewed.
- [ ] Rollback decision recorded if needed.
- [ ] TASKS.md and PROGRESS.md updated when applicable.
