# Screenshot References

Store UI references, bug evidence, and visual comparison material here.

## Handling Rules

- Filename format: YYYY-MM-DD_feature_or_issue_short-description.png
- Add a short adjacent note only when the image needs context: source, target platform, and what is authoritative.
- Screenshots are reference material, not requirements, unless explicitly marked as an approved target.
- Do not rename, edit, move, or delete files here without explicit permission.
